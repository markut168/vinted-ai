# Vinted AI Pro

Versione 2: UI mobile, foto multiple, AI vision, cronologia locale, copia annuncio, dark mode e PWA.

## Avvio
npm install
copia `.env.example` in `.env` e inserisci la tua OPENAI_API_KEY
npm start

Poi apri http://localhost:3000.

## iPhone
Pubblica il progetto su un hosting HTTPS. Aprilo con Safari → Condividi → Aggiungi alla schermata Home.
Per una vera app App Store/TestFlight serve un wrapper iOS (es. Capacitor) e la firma Apple.
